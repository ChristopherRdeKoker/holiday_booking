# Stoep: holiday-home booking demo

A fictional holiday-home booking app with twelve imaginary South African homes. Browse and filter homes, check availability on a calendar, book a stay with a full price breakdown, and view or cancel it under My trips. All homes, prices and bookings are made up, and bookings are saved in the browser.

Built with TypeScript, React 18, Zod and React Hook Form, bundled with Vite and tested with Vitest. Photos are public-domain (CC0) images from Wikimedia Commons, credited in `CREDITS.md` and on the in-app credits page. Run it with `npm ci` and `npm run dev`, and test it with `npm test`.

First version, built over a few days in November 2026.
