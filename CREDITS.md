# Photo credits

The homes in Stoep are fictional, so no photo shows an actual home. Each listing uses a real South African landscape near, or like, its setting. The app shows the same list at `#/credits`.

Every photo is CC0 1.0 (public domain dedication) on Wikimedia Commons. Licences were read from the Commons API (`extmetadata.LicenseShortName`) and the file page templates (`Template:Cc-zero`). The 5 Flickr-sourced files also carry a passed Flickr licence review (`FlickreviewR/pass`). Commons mirrors of Unsplash images were left out on purpose, even where tagged CC0.

All files were fetched through the Wikimedia API on the date shown. The images are stored in `public/photos/` as `<home-id>-600.webp` and `<home-id>-1200.webp`.
